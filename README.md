# はなびメーカー

イラストや文字、手描きのらくがきを打ち上げ花火にして夜空に上げる、単一HTMLのブラウザアプリ。

## 機能

- 画像をアップすると、絵の形の花火が上がる（点描 / 輪郭）
- 文字花火（金・虹・桜・青）
- 簡易ペイント（ペン・消しゴム・太さ）。色は打ち上げごとに自動で配色
- 複数登録、タップで打ち上げ（サイズ小・中・大）、自動連発（サイズランダム）
- ブルーム・残像・ちょっとだけ3D
- 効果音・観客の歓声と拍手（WebAudioで合成）
- 録画（最大30秒・音声付き。Chrome/SafariはMP4、それ以外はWebM）

## 使い方

`index.html` をブラウザで開くだけ。ビルド不要。

## 使用ライブラリ

- three.js r128（cdnjs）
- three.js examples/js のポストエフェクト（EffectComposer, UnrealBloomPass, AfterimagePass ほか）を同梱 — MIT License
